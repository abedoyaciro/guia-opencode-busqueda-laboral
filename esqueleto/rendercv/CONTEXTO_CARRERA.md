## Criterios para cualquier proyecto nuevo

- README orientado a un problema real, no solo a la lista de tecnologías.
- Diagrama de arquitectura y decisiones técnicas.
- Infraestructura reproducible y configuración sin secretos en Git.
- Pruebas, observabilidad, manejo de errores y procedimiento de rollback.
- Evidencia cuantitativa: latencia, disponibilidad, costo, cobertura o tiempo ahorrado.
- Demo, capturas o URL cuando sea seguro publicarla.
- Sección explícita sobre cómo se usó la IA, qué validaciones se aplicaron y qué
  no se delegó al agente.
